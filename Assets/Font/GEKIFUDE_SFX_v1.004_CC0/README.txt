結合濁点・半濁点
- U+3099 COMBINING KATAKANA-HIRAGANA VOICED SOUND MARK
- U+309A COMBINING KATAKANA-HIRAGANA SEMI-VOICED SOUND MARK
- GPOS mark配置対応: ひらがな、カタカナ、英大文字の右上へ配置
- 入力例: あ＋U+3099、う＋U+3099、ウ＋U+3099、カ＋U+309A

Windows Microsoft IMEでは、基底文字を確定後、3099または309Aを全角入力してF5で変換できます。
通常のヴは「vu」で入力できます。

全収録文字とUnicodeの詳細はGLYPHS.txtを確認してください。

ファイル
- GEKIFUDE-SFX-Regular.otf: 推奨。Photoshopなどのデザイン用途向け
- GEKIFUDE-SFX-Regular.ttf: TTFを必要とする環境向け

フォント名
- 日本語環境: 激筆 SFX フォント
- 英語環境: GEKIFUDE SFX
- スタイル: Regular／レギュラー

インストール
1. OTFまたはTTFのどちらか一方を右クリック
2. 「インストール」または「すべてのユーザーに対してインストール」を選択
3. 使用中のアプリを再起動

OTFとTTFは同じファミリー名です。同時にインストールせず、通常はOTFを使用してください。

縦書き
OpenTypeのvert／vrt2に対応しています。
対応アプリでは句読点、リーダー、長音、ダッシュ、括弧類が縦組み用字形へ自動変換されます。
